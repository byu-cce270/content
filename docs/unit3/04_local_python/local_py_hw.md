## Step 6: Ask the User for a Threshold

Rivers are often described by how long the flow stays above a level that matters, such as a flood stage or the minimum flow for a boating season. Add code to the main program that:

1. Asks the user for a flow threshold in cfs with `input()`
2. For each gauge, reports how many **hours** in June 2021 the flow was above that threshold

The readings are 15 minutes apart, so each reading above the threshold counts as 0.25 hours. A comparison such as `flows[:, 0] > threshold` gives an array of `True` and `False` values, and `np.sum` counts the `True` values.

Test it with a threshold of 0 (every gauge should be above it for the whole month: 30 days × 24 hours = 720 hours) and with a threshold larger than every flow in the file (every gauge should report 0 hours).
